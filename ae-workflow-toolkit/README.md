# After Effects Workflow Toolkit

A powerful CEP extension for Adobe After Effects that enhances productivity and streamlines common workflows for motion designers and video editors.

## Features

- **Text Animation Tools**: Quick text animation presets and controls
- **Layer Management**: Advanced layer organization and batch operations
- **Camera Controls**: Enhanced 3D camera management tools
- **Workflow Automation**: Custom scripts for repetitive tasks
- **Export Helpers**: Streamlined export and render queue management

## Installation

1. Download the latest release
2. Copy to your CEP extensions folder:
   - Windows: `C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\`
   - Mac: `/Library/Application Support/Adobe/CEP/extensions/`
3. Restart After Effects
4. Access via Window > Extensions > AE Workflow Toolkit

## Usage

The extension provides custom panels that integrate seamlessly with After Effects:

- **Text Panel**: Create and manage text animations with one-click presets
- **Layer Panel**: Organize and manipulate layers efficiently
- **Camera Panel**: 3D camera controls and presets
- **Automation Panel**: Custom scripts for common tasks

## Requirements

- Adobe After Effects CC 2018 or later
- CEP 8.0 or higher
